# Portfolio Website

A polished personal portfolio website with modern UI/UX. Use this as a base for showcasing your work, skills, and contact details.

## Files
- `index.html` – main page structure
- `styles.css` – responsive visual design
- `script.js` – mobile nav and form interactions

## How to use
1. Open `index.html` in your browser.
2. Customize text, project details, email, and colors.
3. Replace the contact form alert with your preferred form handling.

## Notes
- The design is mobile-friendly and uses clean spacing, accessible typography, and subtle motion.
- Update the email in the contact section to your real address.
